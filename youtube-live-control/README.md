# YouTube Live Control add-on

Schedule and run a channel's YouTube live streams from Home Assistant.

- Schedule from a preset on the dashboard: preset, start, **Schedule**
- Operate from the dashboard: every custom stream key is its own device, so simultaneous streams each get their own panel — pick the stream, **Go Live** when the encoder is connected, **End Stream** when it has stopped; one **Stage** sensor per device says what comes next
- Presets, thumbnails and one-off edits in the add-on's web UI
- Every write verified against YouTube and read back; nothing transitions on its own

See [DOCS.md](DOCS.md) for setup and use.
